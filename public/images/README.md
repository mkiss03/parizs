# Images Directory

Place your tour images in this directory with the following names:

## Required Images:
- `paris-hero.jpg` - Main hero background image (recommended: 1920x1080px)
- `viktoria.jpg` - Your profile photo (recommended: 800x1000px, portrait orientation)
- `tour-classic.jpg` - Classic Paris tour image
- `tour-montmartre.jpg` - Montmartre tour image
- `tour-food.jpg` - Food tour image
- `tour-hidden.jpg` - Hidden Paris tour image

## Image Guidelines:
- Use high-quality, professional photos
- Optimize images before upload (use tools like TinyPNG)
- Recommended formats: JPG for photos, PNG for logos
- Keep file sizes under 500KB for optimal performance
